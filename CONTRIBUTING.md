# Contributing

If something is off, open an issue. If you already know the fix, a small pull request is better.

Please keep the surface area small. This is meant to stay a handful of files, not a dashboard.

I look at:

- GraphQL query changes (repo filters, pagination)
- chart / card layout
- rate-limit and 404 handling

I probably will not take new auth providers or a rewrite in another framework.
